Arraste os botões para a barra de favoritos. O Conector LIST envia as OS direto para o sistema (sem CSV).

1) Conector LIST (recomendado)

Lê a lista logada (OS, serviço, local, solicitação, status e a data da 1ª versão) e grava no Supabase.

Conector LIST (publicar no site)
  1. No site, tela LIST → Gerar token (24h) e copie o token.
  2. Abra a lista no SharePoint logado: .../Lists/Gerenciador de Obras → Todos os itens.
  3. Clique no favorito Conector LIST e cole o token quando ele pedir.
  4. Volte ao site → LIST → Atualizar.

2) Extrair para CSV (alternativa, não envia nada)

Só baixa o CSV com as OS e as datas — útil para conferência ou importação manual.
